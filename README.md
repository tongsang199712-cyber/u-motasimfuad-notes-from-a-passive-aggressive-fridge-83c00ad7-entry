One funny passive-aggressive note a smart fridge leaves for its owner. The leftovers the owner swore they'd eat tonight turned six today, so the fridge threw them a little birthday party — and the owner wasn't invited. Dry, petty, and exactly the sort of thing a smug appliance would keep on its door screen.

## Run it

```sh
node main.ts
```

This writes the note to `/output/entry.txt` (one line, 118 characters, no trailing newline) and prints the character count, byte count, and the line.
